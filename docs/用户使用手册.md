## 2. 系统用途

项目账册用于统一管理以下业务数据：

- 项目全览、项目台账及项目资金汇总；
- 支持协议和执行协议；
- 银行日记账及本方银行账户；
- 发票台账；
- 支持方库和执行方库；
- 专家资料、资质和复核状态；
- 专委会、会员及多期会费；
- PM 名册和登录账号。

系统以项目编码为业务主线。合同、银行流水和发票保存后，项目的应收、已收、已开票、应付及已付金额会自动更新，不需要在项目台账中重复填写。

## 3. 账号与权限

### 3.1 账号类型

| 账号类型 | 业务数据范围 | 写操作 | 项目/专家复核 | PM 管理 | 账号管理 |
| --- | --- | --- | --- | --- | --- |
| 系统管理员 | 全部模块 | 可以 | 可以 | 可以 | 可以 |
| 普通管理员 | 按模块设置 | 按模块设置 | 需对应模块“复核”权限 | 不可以 | 不可以 |
| PM | 仅限绑定 PM 负责的业务数据 | 四个台账默认可编辑，四个库按权限设置 | 专家库可按权限复核 | 不可以 | 不可以 |
| 访客 | 全部模块只读 | 不可以 | 不可以 | 不可以 | 不可以 |

说明：

- 系统管理员可以创建系统管理员、普通管理员、PM 和访客账号。
- 普通管理员可对项目、合同、银行、发票、支持方、执行方、专家和会员模块分别设置“无权限”、“可查看”或“可编辑”。
- 项目台账和专家库还可设置“复核”，该级别同时包含查看和编辑权限。
- PM 账号必须绑定一个已有 PM；项目、合同、银行流水、发票及四个资料库均由后端限制为该 PM 负责的数据。
- PM 默认可使用项目、合同、银行和发票四个台账；支持方、执行方、专家和会员四个库分别设置无权限、查看、编辑，专家库可设置复核。
- 访客只能查询和查看，不显示新增、编辑、停用、作废、复核等操作按钮。
- PM 业务名册与 PM 登录账号分开维护，同一 PM 最多绑定一个账号。

### 3.2 登录与退出

1. 使用浏览器打开系统地址。
2. 输入管理员提供的用户名和密码。
3. 单击“登录”。
4. 登录成功后默认进入“项目台账”。
5. 需要退出时，单击左下角当前用户区域右侧的退出按钮。

登录失败时，请检查用户名、密码和账号状态。连续失败时联系系统管理员重置密码或确认账号是否已停用。

## 4. 页面与通用操作

### 4.1 导航结构

| 分组 | 页面 |
| --- | --- |
| 项目管理 | 项目全览、项目台账、项目详情 |
| 业务台账 | 合同台账、银行日记账、发票台账 |
| 基础资料 | 支持方库、执行方库、专家库、会员库 |
| 系统管理 | PM 管理、账号管理 |

“账号管理”和“PM 管理”只对系统管理员显示。普通管理员只显示已授予查看或更高权限的业务模块。

### 4.2 搜索

- 顶部全局搜索框用于搜索项目编码或项目名称，按回车后进入项目台账并显示搜索结果。
- 各页面列表上方的搜索框只搜索当前台账或资料库。
- 项目、PM、支持方、执行方、专家、会员和专委会等下拉框支持输入关键字搜索。
- 搜索无结果时，先检查对应资料是否已建立并处于启用状态。

### 4.3 分页

- 常规列表每页显示 20 条记录。
- 数据超过一页时，页面底部显示上一页、页码、下一页和当前记录范围。
- 会员库中的专委会目录每页显示 4 个专委会。
- 修改搜索条件后，列表自动返回第一页。

### 4.4 日期与金额

- 日期控件按“年/月/日”选择，新增项目、合同、发票和专家时不默认选择当天。
- 金额最多保留两位小数，直接输入数值即可。
- 发票税率按百分数填写，例如输入 `6` 表示 `6%`。
- 项目周期使用“整数 + 月/年”录入，例如 `3 月` 或 `1 年`。

### 4.5 编辑、停用、删除和作废

系统优先保留业务历史记录，因此大部分“删除”操作并不是物理删除：

| 操作 | 结果 |
| --- | --- |
| 项目结项/中止 | PM 提交状态申请，管理员复核通过后生效 |
| 项目归档 | 已结项或已中止项目由 PM 申请，管理员复核通过后转为已归档 |
| 作废合同 | 合同不再参与项目应收或应付汇总 |
| 作废银行流水 | 流水不再参与结算，相关项目或会费金额自动回退 |
| 作废发票 | 发票不再计入项目已开票金额 |
| 停用基础资料 | 不再出现在新业务的下拉框中，历史记录保留 |
| 停用账号 | 账号不能继续登录，历史操作记录保留 |

执行不可逆操作前，系统会显示确认窗口和影响说明。请核对记录后再确认。

### 4.6 筛选后导出

- 仅系统管理员可以在项目台账、合同台账、银行日记账、发票台账、支持方库、执行方库、专家库和会员库使用“导出筛选结果”。
- 系统按当前页面已生效的搜索和筛选条件生成 Excel；导出范围为全部筛选结果，不受当前页码限制。
- 专家库导出包含完整手机号、身份证号码和银行账号；银行日记账导出包含完整本方及对方银行账号。下载前需二次确认，操作会写入审计日志。
- 会员库导出文件包含“会员库”和“会费明细”两个工作表，保留每位会员的全部会费记录。
- 单次最多导出 20,000 条主记录。超过限制时需增加搜索或筛选条件后重新导出。

## 5. 推荐业务操作顺序

新业务建议按以下顺序建立资料：

1. 在“PM 管理”中建立负责 PM。
2. 在“支持方库”和“执行方库”中建立合作机构。
3. 在“专家库”中录入专家，并完成复核。
4. 如涉及会员业务，先成立专委会，再新增会员和会费应收。
5. 在“银行日记账”的“本方账户管理”中建立本方银行账户。
6. 在“项目台账”中新建项目。
7. 在“合同台账”登记支持协议或执行协议。
8. 在“银行日记账”登记支持款收入、执行款支出或专家费支出。
9. 在“发票台账”登记项目发票。
10. 返回项目详情核对资金轨道和来源明细。

会员会费收入不关联项目，可在完成第 4、5 步后直接录入银行流水。

## 6. PM 管理

### 6.1 新增 PM

1. 进入“系统管理 > PM 管理”。
2. 单击“新增 PM”。
3. 填写姓名；所属部门可选填。
4. 单击“保存”。

新增后，该 PM 可用于项目经理、机构负责 PM、会员负责 PM、专委会负责 PM 和专家填表人等字段。

### 6.2 编辑或停用 PM

- 单击“编辑”可修改姓名、所属部门和状态。
- PM 姓名修改后，会同步更新其已关联项目中的姓名显示。
- 单击“停用”后，该 PM 不再出现在业务表单下拉框中，但历史关联不受影响。
- 如需恢复，可编辑该 PM 并将状态改为“正常”。

## 7. 项目台账

### 7.0 项目全览

1. 进入“项目管理 > 项目全览”。
2. 可按平台、立项时间范围、项目性质和项目类型组合筛选，也可输入项目编码或名称查询。
3. 列表展示 PM、立项金额、支持协议金额和实收金额。支持协议金额来自已签署的支持协议，实收金额来自已确认的支持款收入流水。
4. “回款刻度”按“实收金额 ÷ 支持协议金额”计算；单击项目行可进入项目详情。筛选结果较多时按每页 20 条分页展示。

### 7.1 新建项目

1. 进入“项目管理 > 项目台账”。
2. 单击“新建项目”。
3. 填写以下内容：

| 字段 | 填写说明 |
| --- | --- |
| 项目名称 | 项目的完整业务名称 |
| 平台 | 项目所属业务平台 |
| 平台缩写 | 手动填写 1 至 10 位英文字母，系统自动转为大写；保存后不可修改 |
| 项目性质 | 按实际业务性质填写 |
| 项目类型 | 按实际项目类型填写，用于项目全览筛选 |
| 发布日期 | 选择年、月、日 |
| 项目经理 | 从启用的 PM 中搜索选择 |
| 项目周期 | 输入整数并选择“月”或“年” |
| 立项金额 | 项目立项基准金额 |
| 执行成本 | 项目计划执行成本 |
| 备注 | 可选填 |
| 附件列表 | 可选，上传项目相关 PDF |

4. 单击“保存项目”。

系统根据平台缩写和发布日期自动生成项目编码。格式为“平台缩写 + 两位年份 + 两位月份 + 当月序号 + 5 位随机大写字母”，例如 `SL260701OCHWK`。序号按同一平台缩写、同一年月独立计数，不足两位时补零，超过 `99` 后自然扩展为 `100`、`101`，不会截断或重复使用。新建项目默认为“进行中”和“未归档”。

### 7.2 查询、编辑和状态复核

- 使用搜索框按项目编码、名称或平台查询。
- 单击“编辑”可修改项目基础信息和附件。
- 已归档项目只允许查看，不能再编辑基础信息或附件。
- 项目状态只有进行中、已结项、已中止三种；归档状态只有未归档和已归档两种。
- PM 账号可对本人负责的进行中项目提交“已结项”或“已中止”申请。
- 项目结项或中止后，PM 账号可提交“已归档”申请。
- 系统管理员或拥有项目“复核”权限的普通管理员可通过或驳回；通过后才更新有效状态。
- 系统记录申请人、申请时间、复核结果、复核人和复核时间。

### 7.3 查看项目详情

单击项目行或“查看详情”，进入项目详情页。详情页包含：

- 项目概览：项目编码、日期、PM、性质、金额、周期和备注；
- 项目资金轨道：立项金额、支持协议、已收支持款、已开票、执行成本、执行协议、已付执行款和已付专家费；
- 合同页签：当前项目的支持协议和执行协议；
- 流水页签：当前项目关联的资金流水；
- 发票页签：当前项目关联的发票。

资金轨道中的金额均由相关台账自动汇总，不能在项目编辑窗口直接修改。

## 8. 支持方库与执行方库

### 8.1 新增机构

1. 进入“支持方库”或“执行方库”。
2. 单击“新增支持方”或“新增执行方”。
3. 填写机构名称、入库平台、负责 PM 和入库时间。
4. 联系人和联系电话可选填。
5. 单击“保存”。

系统按“入库平台 + 规范化机构名称”组合检查重复：只有两项同时相同时才会提示重复；机构名称相同但入库平台不同，可以分别建立记录。

### 8.2 编辑与停用

- 单击“编辑”可以修改机构资料或恢复已停用机构。
- 单击“停用”后，机构不再出现在新合同的选择列表中。
- 已签合同和历史项目关系不会因停用而删除。
- 支持方只能用于支持协议，执行方只能用于执行协议。

## 9. 合同台账

### 9.1 登记合同

1. 确认关联项目及支持方或执行方已建立并启用。
2. 进入“业务台账 > 合同台账”。
3. 单击“登记合同”。
4. 填写关联项目、合同主体、合同类型、合同金额和签约日期。
5. 根据合同类型选择支持方或执行方。
6. 按需逐份添加 PDF 附件。
7. 单击“保存支持协议”或“保存执行协议”。

合同类型及汇总关系：

| 合同类型 | 可选相对方 | 对项目汇总的影响 |
| --- | --- | --- |
| 支持协议 | 支持方 | 增加项目应收金额 |
| 执行协议 | 执行方 | 增加项目应付执行款 |

所有启用的执行方都可以用于登记执行协议，不需要执行方遴选。

### 9.2 编辑与作废

- 有效合同可以编辑，保存后项目汇总自动重新计算。
- 单击“作废”并确认后，合同不再参与项目汇总。
- 已作废合同不能继续编辑，也不能恢复；如需更正，应重新登记正确合同。

## 10. 银行日记账

### 10.1 管理本方银行账户

首次录入流水前，需要建立本方银行账户：

1. 进入“银行日记账”。
2. 单击“本方账户管理”。
3. 单击“新增账户”。
4. 填写银行名称和银行账号。
5. 单击“保存”。

银行账号会加密保存，列表和下拉框只显示脱敏账号。重复银行账号不能再次建立。账户停用后不再出现在新流水中，历史流水仍保留。

### 10.2 录入银行流水

1. 单击“录入流水”。
2. 首先选择收支方向和资金分类。
3. 根据资金分类选择项目、专家或会员。
4. 选择本方银行账户。
5. 填写对方账户名称、银行名称和银行账号。
6. 填写交易日期、金额和性质；交易日期仅保存年月日，不记录时间。
7. 按需逐份添加 PDF 附件。
8. 单击“保存流水”。

四类资金分类规则如下：

| 收支方向 | 资金分类 | 必须关联 | 保存后的业务影响 |
| --- | --- | --- | --- |
| 收入 | 支持款收入 | 项目 | 增加项目已收支持款 |
| 收入 | 会员会费收入 | 会员，不关联项目 | 按应缴日期从早到晚冲抵会员未缴会费 |
| 支出 | 执行款支出 | 项目 | 增加项目已付执行款 |
| 支出 | 专家费支出 | 项目和已通过专家 | 增加项目已付专家费 |

选择“专家费支出”时，系统会根据所选专家自动填写对方账户名称、银行名称和银行账号，填写后仍可修改。

选择“会员会费收入”时：

- 只能选择存在未缴或部分缴纳会费的启用会员；
- 不显示关联项目字段；
- 流水金额不能超过该会员全部未缴会费；
- 一笔流水可以依次冲抵该会员多期会费；
- 保存成功后，会员库中的实收金额和状态自动更新。

### 10.3 使用模板导入

1. 单击“模板导入”，下载 CSV 模板。
2. 使用 Excel 打开模板并填写，保存时保持 CSV 格式。
3. 交易日期填写“年/月/日”；项目填写项目编码；专家费填写专家姓名和专家身份证号，对方账户名称、银行名称和银行账号留空，由系统从专家库自动匹配；会员会费填写专委会编码和会员姓名。
4. 选择填写后的 CSV 文件并单击“开始导入”。
5. 查看总行数、成功数和逐行失败原因，修正失败行后可再次导入。
6. 导入内容包含专家费时，系统自动下载“专家费导入匹配及个税”CSV；也可在结果区域再次下载。文件包含入库匹配状态、专家职称、证件号、手机号、开户行、银行卡号和自动计算的个税。

专家必须使用姓名和身份证号联合匹配；只有已通过且未停用、银行资料完整的专家费行可以成功导入。个税按劳务报酬应纳税所得额和系统配置的三级税率、速算扣除数计算，结果保留两位小数。敏感信息返表会写入审计日志。

单次最多导入 1000 行，文件不超过 2MB。同一流水重复导入时会被拦截。导入成功的流水与手工录入流水一样可以编辑和作废。

### 10.4 编辑与作废流水

- 未作废的手工或模板导入流水可以编辑，包括已匹配流水。
- 编辑金额、分类或关联对象后，原业务分配会撤销并按新内容重新生成。
- 单击“作废”后，流水不再参与项目或会费结算。
- 作废会费流水时，相关会费实收金额和状态会自动回退。
- 已作废流水不能继续编辑，也不能恢复。

## 11. 发票台账

### 11.1 登记发票

1. 进入“业务台账 > 发票台账”。
2. 单击“登记发票”。
3. 选择发票方向：“已开票”表示我方开出的发票，“已收票”表示我方收到的发票。
4. 搜索并选择关联项目。
5. 填写发票日期、发票类型、开票平台，以及购买方名称或销售方名称。
6. 填写价税合计和税率。
7. 核对系统自动倒算的金额和税额。
8. 按需逐份添加 PDF 附件。
9. 单击“保存发票”。

计算规则：

- 金额 = 价税合计 ÷（1 + 税率）；
- 税额 = 价税合计 - 金额；
- 金额和税额保留两位小数；
- 只有正常状态的“已开票”会计入项目已开票金额，“已收票”不计入该汇总。

### 11.2 编辑与作废

- 正常状态的已开票和已收票均可编辑。
- 已开票作废后不再计入项目已开票金额；已收票作废后保留记录但不再视为有效收票。
- 已作废发票不能继续编辑，也不能恢复。

### 11.3 模板批量导入

1. 在发票台账单击“模板导入”。
2. 下载 CSV 导入模板，并使用 Excel 填写。
3. 发票方向填写“已开票”或“已收票”，关联项目填写项目编码，发票日期填写“年/月/日”。
4. 填写价税合计和税率（百分数，例如 `6` 表示 `6%`）；金额和税额由系统自动倒算。
5. 保持 CSV 格式上传并单击“开始导入”。
6. 查看成功、失败数量及具体失败行，修正失败数据后可再次导入。

单次最多导入 1000 行，文件不超过 2MB。只能匹配进行中的项目，PM 账号只能导入其本人负责的项目。

## 12. 专家库

### 12.1 新增专家

1. 进入“基础资料 > 专家库”。
2. 单击“新增专家”。
3. 按实际情况填写以下资料：姓名、单位、职称、手机、身份证号码、开户行、银行账号、入库时间、邮箱、专业/科室、职务和填表人-PM。
4. 按需逐份上传职称证明、工作证或医师执业证 PDF。
5. 单击“保存”。

姓名和填表人-PM为必填项。新专家保存后进入“待复核”状态。

### 12.2 专家状态与可用操作

| 当前状态 | 可执行操作 | 状态变化 |
| --- | --- | --- |
| 待复核 | 编辑、查看敏感信息、通过、驳回 | 通过后为已通过；驳回后为已停用 |
| 已通过 | 编辑、查看敏感信息、停用 | 停用后为已停用 |
| 已停用 | 无 | 不可恢复或继续操作 |

只有“已通过”的专家可以在银行日记账中用于专家费支出。

### 12.3 敏感信息和资质附件

- 专家列表中的手机、身份证号码和银行账号只显示脱敏值。
- 系统管理员和普通管理员可以单击“敏感信息”查看完整值。
- 查看完整敏感信息和下载资质附件会记录审计日志。
- 编辑专家时，手机、身份证号码和银行账号留空表示保留原值。
- 已停用专家不能查看敏感信息、下载资质或继续编辑。

## 13. 会员库

### 13.1 成立专委会

1. 进入“基础资料 > 会员库”。
2. 单击“成立专委会”。
3. 填写专委会编码、成立日期、专委会名称和负责 PM。
4. 单击“保存专委会”。

专委会名称不能重复。可以在专委会目录中按名称或编码搜索，也可以编辑或停用专委会。

### 13.2 新增会员

1. 单击“新增会员”。
2. 填写会员名称。
3. 搜索并选择所属专委会。
4. 填写会员类别和会员职务；会员职务手工填写，例如顾问、主任委员、副主任委员、秘书或副秘书。
5. 选择负责 PM，按需填写入会日期。
6. 选择是否已发放会员证书。
7. 按需逐份添加 PDF 附件，最多 10 份，单份不超过 10MB。
8. 单击“保存会员”。

会员停用后不能用于新会费流水，但历史会费记录保留。编辑会员时可以重新启用。

### 13.3 新增和查看会费

1. 在会员行中单击“会费”。
2. 填写应收编号、应收金额；缴费期次和应缴日期可按需填写。
3. 单击“保存”。
4. 需要查看全部历史会费时，单击“记录”或“查看全部 N 笔”。

每个会员可以有多笔会费。会费记录按应缴日期倒序展示，支持分页、编辑和免除。

会费状态包括：

| 状态 | 含义 |
| --- | --- |
| 未缴 | 尚无有效会费收入流水 |
| 部分缴纳 | 实收金额大于 0，但未达到应收金额 |
| 已缴 | 实收金额达到应收金额 |
| 已免除 | 该笔应收已被人工免除 |

实际收款必须在“银行日记账”中使用“会员会费收入”登记，不要直接修改实收金额。

## 14. 账号管理

本页面仅系统管理员可见。

### 14.1 新增账号

1. 进入“系统管理 > 账号管理”。
2. 单击“新增账号”。
3. 填写姓名、登录用户名和初始密码。
4. 选择系统管理员、普通管理员、PM 或访客。
5. 普通管理员：在权限矩阵中为每个业务模块选择无权限、可查看或可编辑；项目台账和专家库可选“复核”。
6. PM 账号：必须搜索并绑定已有 PM，并设置四个资料库的权限；普通管理员、系统管理员和访客不绑定 PM。
7. 单击“保存”。

初始密码至少 8 个字符。应通过安全方式交给使用者，并要求其及时修改。

### 14.2 编辑、重置密码和停用

- 单击“编辑”可修改姓名、用户名、类型、权限矩阵、PM 绑定和状态。
- “重置密码”留空表示不修改密码。
- 当前登录的系统管理员不能修改自己的账号类型或停用自己。
- 单击“停用”后，该账号不能继续登录。
- 需要恢复账号时，编辑账号并将状态改为“正常”。

## 15. PDF 附件

项目、合同、银行流水、发票和专家资质支持 PDF 文件。

统一规则如下：

- 仅支持 PDF；
- 每条业务记录最多 10 份；
- 单个文件不超过 10 MB；
- 每次选择一份文件，选择后可继续添加下一份；
- 保存表单前可以从“待上传”列表中移除文件；
- 编辑记录时可以继续添加或删除已有附件；
- 业务数据与附件分别保存，出现“业务已保存，但附件上传失败”时，应进入编辑窗口重新上传失败文件。

建议上传前使用清晰、可识别的文件名，例如 `2026项目支持协议-某机构.pdf`。

## 16. 数据汇总规则

| 项目详情金额 | 数据来源 |
| --- | --- |
| 支持协议/应收金额 | 有效支持协议金额合计 |
| 已收支持款 | 有效“支持款收入”银行流水合计 |
| 已开票 | 有效发票价税合计 |
| 执行协议/应付执行款 | 有效执行协议金额合计 |
| 已付执行款 | 有效“执行款支出”银行流水合计 |
| 已付专家费 | 有效“专家费支出”银行流水合计 |

合同、流水或发票被编辑、作废后，相关项目汇总自动重新计算。会员会费流水被编辑或作废后，会费状态也会自动重新计算。

## 17. 常见问题

### 17.1 页面没有新增、编辑或作废按钮

当前账号很可能是访客账号。请联系系统管理员确认账号类型。

### 17.2 下拉框找不到 PM、机构、项目或专家

请依次检查：

- 对应资料是否已经建立；
- 资料是否处于启用状态；
- 项目是否仍处于进行中；
- 专家是否已经通过复核；
- 搜索关键字是否正确。

### 17.3 会员会费收入找不到会员

只有启用且存在未缴或部分缴纳会费的会员会出现在选择列表中。请先在会员库新增会费应收。

### 17.4 会费流水金额无法保存

会费流水金额不能超过该会员当前全部未缴会费。请核对各期应收和已收金额，必要时拆分流水。

### 17.5 附件上传失败

确认文件为 PDF、单个文件不超过 10 MB、该记录附件总数不超过 10 份。若业务记录已经保存，可编辑该记录后重新添加附件。

### 17.6 看不到专家完整身份证或银行账号

访客无权查看完整敏感信息。系统管理员和普通管理员应通过专家行中的“敏感信息”按钮按需查看，不要在普通备注或截图中传播完整信息。

### 17.7 作废后能否恢复

项目取消、合同作废、银行流水作废、发票作废和专家停用目前不能直接恢复。操作前应仔细核对；确需纠正时，按业务要求重新登记正确记录。

### 17.8 数据没有立即变化

先等待当前保存操作完成，再返回列表或项目详情。仍未更新时可刷新浏览器；不要连续重复单击保存按钮。

## 18. 安全使用要求

- 不要共享账号，每位使用者应使用独立账号。
- 不要在聊天工具、普通邮件或截图中传播密码、完整身份证号码和银行账号。
- 离开电脑前退出系统或锁定屏幕。
- 只在确认无误后执行作废、停用和复核操作。
- 发现账号异常、数据异常或敏感信息泄露时，立即联系系统管理员。
- 系统管理员应定期检查备份、磁盘空间和账号状态，并限制服务器 SSH 访问来源。
